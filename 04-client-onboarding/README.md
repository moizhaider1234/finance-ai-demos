# 04 - Client onboarding workflow (DEMO BUILD)
**Problem:** every new client needs folders, a letter, a checklist and tasks, all set up by hand.
**How it works:** intake form -> normalise data (US/UK checklist differs, e.g. VAT vs state sales tax) -> Drive client folder + 5 subfolders -> copy the engagement letter template and fill placeholders -> DRAFT document-checklist email and DRAFT welcome email -> 5 onboarding tasks appended to a Sheet.
**Set up:** make a Google Doc from `engagement_letter_template.md`, put its URL and your clients root folder URL in the nodes marked PASTE_. Tasks tab columns: `client, task, owner, status, due_in_days, created`.
**Not included (be honest on LinkedIn):** e-signature, and payment collection.
