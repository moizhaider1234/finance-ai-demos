# Finance AI Automation Demos (n8n) - Moiz Haider
Seven demo builds for accounting firms and bookkeepers (US and UK). **All data is synthetic. These are demo builds, not client results.**

| # | Project | Folder | Offline-verified here |
|---|---|---|---|
| 1 | Invoice ingestion + categorization | `01-invoice-ingestion` | 20 PDFs extract cleanly; evaluator self-tested |

## Honest status
- **Tested in n8n:** all 7 workflows were rebuilt with the n8n Workflow SDK, created in a real n8n cloud instance and run there with simulated Drive/Sheets/Gmail/OpenAI/PDF responses. Code nodes, branching and the maths ran for real (e.g. 4 correct overdue-invoice drafts from 7 invoices, a refused tax-advice question, a flagged bad invoice, correct report maths).
- **Not tested:** live Google/Gmail/OpenAI calls, real PDF extraction inside n8n, and Gotenberg PDF conversion. No credentials were attached when testing.
- **`*/workflow.json` files in this repo** were generated by `tools/build_workflows.py` and only structure-checked. They are NOT the n8n-tested versions. To get the tested ones, open each workflow in n8n, use the three-dot menu > Download, and replace the file here.
- Expect to attach credentials and paste Sheet/Drive URLs where marked PASTE_ or placeholder.
